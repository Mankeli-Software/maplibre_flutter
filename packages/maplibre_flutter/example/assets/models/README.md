# Example 3D models

## `demo_vehicle.glb` — bundled, original work

Generated by [`../../tool/make_demo_model.py`](../../tool/make_demo_model.py) and
covered by this repository's licence. Regenerate with:

```bash
cd packages/maplibre_flutter/example
python3 tool/make_demo_model.py
```

It is deliberately tiny (~3.8 KB) and deliberately ugly. It exists to exercise the
paths that actually broke while the model renderer was built, not to look good:

| Property | What it tests |
|---|---|
| Two materials, one `alphaMode: BLEND` | opaque-before-blended part ordering — glass drawn first used to depth-cull the bodywork behind it |
| UVs spanning `[0, 3]` | REPEAT wrapping — clamping collapses such a model to a single edge colour |
| Asymmetric silhouette, distinct front | heading and facing errors, which hide behind symmetric shapes |
| A node transform | transform baking |
| Authored in metres, nose along `-Z` | life size at `scale: 1`, and glTF's forward convention |

## Models used for testing but **not** redistributed here

The renderer was developed and verified against a real production model, which is
**not** included in this repository — it is 36 MB, which is permanent weight for a
test fixture. Point the example at your own copy instead:

```bash
flutter run -d macos \
  --dart-define=MODEL_GLB=/absolute/path/to/2024_maruti_suzuki_alto_k10_vxi.glb \
  --dart-define=MODEL_SCALE=0.394 \
  --dart-define=MODEL_HEADING=180
```
